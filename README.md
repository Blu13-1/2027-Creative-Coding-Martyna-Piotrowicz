<h2> If Statement</h2>
<p>
    In this sketch I explored how to use if and else if statements. "If" means when a certain event or trigger happens, the code should run the code in the if statement, "else if" is when "if" was not triggered then run the code in "else if". It is similar to a boolean. For this sketch I used drew two lightbulbs with mouse interactions. When the mouse touches the middle lightbulb, the lightbulb turns red and shrinks, but when the mouse does not touch the middle lightbulb, it grows back in its original size. When the mouse touches the first lightbulb, it turns blue and moves upward, although when the mouse does not touch the first lightbulb it returns to its original place. 
</p>

<h2> Loops and Arrays </h2>
<p>
    For loops I used the common iteration the "for" structure. Iteration lets me repeat an intruction in my code multiple times, which creates a loop. An array is a list of data, identified by an index number. It can be useful to store list of variables and manage values. The "for" loops and arrays usually work together in code. I have explored using loops and arrays in bubble sort and "building sort".
</p>

<h2> Exploration of Classes </h2>
<p> 
    A class is a blueprint for an object with its sets of data and functions. For this I have explored classes by using Bubbles as an example for class in Bubble sort. The object in this case is bubbles and it has its own set of variables such as x, y positions and size and also its own functions such as moving upwards. For interaction I have added mouse interaction where whenever a mouse is pressed a single bubble floats faster than the background bubbles.

<h2> Interactive Image through Sound and Particles</h2>
<p>
